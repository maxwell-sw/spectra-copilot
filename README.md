# Spectra Copilot

> **从原始光谱到可解释的材料决策。**一个面向材料、光学与热管理研究的本地 Research Agent：LLM 负责理解研究任务与选择下一步，Harness 负责把权限、上下文、工具、计算和交付物锁在可验证的轨道上。

你不必把任务拆成“导入文件 → 填参数 → 点计算 → 自己整理结果”。例如可以直接说：

> “比较这批样品在太阳波段与 8–13 μm 的表现，筛出值得继续验证的候选材料，给我一张对比图和一份组会报告。”

Spectra Copilot 会先识别数据和研究目标、追问真正缺少的条件，再按需调用本机工具；最后交付真实数据绘制的图、可复算的指标、带限制条件的解释和 HTML 报告。

> A local, tool-using spectral-analysis Agent for materials, optics, and thermal-management research.

## 为什么它是 Agent，而不只是计算器

| 层 | 作用 | 不做什么 |
| --- | --- | --- |
| **LLM 研究协作层** | 理解自然语言任务、合并上下文、选择工具、提出必要追问、解释结果与组织报告 | 不直接计算积分，不凭图像或记忆编造数值 |
| **Agent Harness** | 意图路由、会话记忆、权限检查、计算条件闸门、工具调用循环、执行轨迹与交付物版本化 | 不让模型越过授权读取文件或随意重建已有成果 |
| **确定性光谱工具层** | 解析、质检、单位换算、插值、波段特征、ASTM/黑体加权、绘图、报告与导出 | 不修改原始数据，也不把研究建议伪装成实验结论 |

核心原则是：**模型负责“该做什么”，代码负责“事实是什么、能不能做”。** 因此它既保留自然语言 Agent 的灵活性，也让每个数值、图和结论都能追溯到已授权数据与本机工具结果。

```text
自然语言研究任务 + 已授权光谱文件
                ↓
LLM：理解目标、规划、选择工具、追问与解释
                ↕
Harness：上下文 / 权限 / 条件检查 / 工具轨迹 / 产物版本
                ↕
本机确定性工具：解析、物理计算、绘图、报告、导出
                ↓
可复算的图、表、候选材料比较、研究建议与报告
```

## 它能解决哪些研究任务

Spectra Copilot 不把“哪种材料更好”简化成一次点击。它会根据可获得的数据类型、单位、公共覆盖波段和实验前提，给出**限定条件下的可复算比较**。

| 研究问题 | Agent 的工作方式 | 交付结果 |
| --- | --- | --- |
| **辐射制冷候选筛选** | 检查 0.3–2.5 μm 与 8–13 μm 的覆盖；在确认反射率/透射率/发射率含义后，计算太阳 ASTM G173 或指定温度下的黑体加权指标 | 覆盖提示、加权指标、对比图、候选排序与仍需验证的前提 |
| **红外辐射特征 / 隐身候选比较** | 围绕用户指定的工作波段，提取峰谷、均值、趋势和黑体加权表现；检查反射率能否在不透明或已知透射率条件下推断发射率 | 波段特征表、同图对比、带假设的工程解释 |
| **光学涂层与材料选型** | 比较多样品的公共覆盖范围、单位和 Y 值含义，避免把不同条件的数据直接排名 | 可比性检查、筛选依据、真实多曲线 SVG 图 |
| **仪器数据接收与排错** | 识别列结构、分隔符、表头、无效行、重复波长、异常值和候选单位；需要时审计原始行号 | 数据质量摘要、异常定位与待确认事项 |
| **组会 / 答辩 / 论文式汇报** | 先收集工具事实，再生成含真实谱图、方法、结果、AI 解释、限制与假设的报告 | 本地 HTML 报告，可直接在浏览器打印为 PDF |
| **下一步实验设计** | 依据已有覆盖范围和计算结果提出补测波段、温度或对照实验建议，并区分事实与建议 | 有证据边界的实验建议，而不是虚构机理结论 |

这意味着它可以服务辐射制冷、红外辐射调控、光学涂层比较、太阳光谱响应、材料筛选和科研汇报；但它不会在数据不足时声称材料已经“最优”或机理已经被证明。

## 现有工具箱

工具由 Agent 按任务按需调用，普通问答不会无故生成文件或执行计算。当前实现的核心工具包括：

| 工具能力 | 本机工具 | 用途 |
| --- | --- | --- |
| 文件理解与授权读取 | `get_selected_spectrum_summaries` | 在用户授权范围内读取文件摘要、点数、候选单位、范围和提醒 |
| 原始数据审计 | `scan_raw_spectrum_rows` | 按阈值、极值或异常定位最多 30 行原始 X/Y 数据与近似源行号 |
| 语义与上下文记忆 | `update_task_context`、`confirm_spectrum_meanings` | 理解“300 K”“刚才的范围”“这些都是反射率”等自然语言条件并写入结构化状态 |
| 专业约定查询 | `get_legacy_demo_contract` | 读取项目内 ASTM、绘图和积分约定，避免模型凭记忆替代方法 |
| 光谱特征分析 | `summarize_band_features` | 计算指定波段的均值、极值、极值位置和趋势 |
| 物理加权计算 | `calculate_weighted_metrics` | 对 nm 数据使用 ASTM G173 AM1.5G，对 μm/波数数据按指定温度进行 Planck 黑体加权与梯形积分 |
| 科学可视化 | `generate_spectrum_chart`、`generate_comparison_chart` | 基于原始点生成单样品或多样品真实谱图与波段标注 |
| 报告与网页交付 | `generate_analysis_report`、`generate_custom_html_deliverable` | 生成带真实谱图和工具事实的 HTML 报告或自定义网页交付物 |
| 可追溯修改 | `read_current_artifact`、`patch_current_html_artifact` | 使用 `@交付物` 锁定已有成果，只创建该成果的下一版本，避免误改其他文件 |
| 数据导出 | `/api/weighted-export` | 将已得到的加权结果导出为 CSV 或 Excel |

## 一次任务是怎样完成的

1. **接收数据与任务**：从 Desktop 范围内查找或上传 CSV、TXT、TSV、DPT、XLSX 光谱文件；单次最多 30 份。
2. **建立可信上下文**：检查分隔符、表头、无效行、重复波长、排序、Y 值范围、波段覆盖和候选单位；物理计算前必须由用户确认单位与物理含义。
3. **LLM 选择最小必要工具**：优先读取摘要，只有需要时才审计原始行，再进行特征分析、加权计算、出图或报告。
4. **Harness 守住边界**：缺少波段、温度或确认信息时暂停并追问；默认最多 5 轮工具调用，避免无限循环和无谓成本。
5. **交付并保留证据**：聊天中显示工具轨迹；图、报告和数据导出均以本机工具结果为基础。针对 `@图` 或 `@报告` 的修改只更新该产物的下一版本。

## 可信性与数据边界

- **不让 LLM 心算**：单位换算、插值、ASTM/黑体权重、梯形积分、CSV/Excel 和绘图数据均由本机确定性代码完成。
- **不静默改数据**：自动单位判断只是候选提示；清洗、换算或物理结论需要相应的确认条件。
- **最小化送入模型的数据**：模型通常只看到文件名、摘要、确认状态和计算结果。只有用户请求排错时，工具才会提供最多 30 行已授权原始 X/Y 数据；不会把整份桌面文件直接交给模型。
- **结果与建议分层**：报告区分工具事实、AI 解释、研究建议、限制与待确认项；不能把相关性写成机理证明。
- **不伪造失败**：模型服务不可用、数据覆盖不足或计算条件不全时，Agent 会明确失败或追问，不会生成看似合理的假结果。

这一版本地原型支持用户自带 DeepSeek 或其他 OpenAI 兼容服务的 Key。Key 与模型设置保存在**当前浏览器、当前设备**的本地存储中，直到用户点击“清除 Key”；它们不会写入项目文件、压缩包或服务端日志。每次模型调用由该用户自己的 Key 发起，因此费用由该 Key 所属账户承担。

## 快速开始

需要 Node.js 20 或更高版本。进入项目目录后运行：

```bash
npm install
npm test
npm start
```

然后在浏览器打开 <http://127.0.0.1:8787>。

## 在线演示版：让任何人通过链接体验

**在线体验：<https://spectra-copilot.onrender.com/>**

仓库可以以公共上传模式部署为 HTTPS 网页。访问者打开链接后上传自己的光谱文件，再在浏览器中填入自己的 DeepSeek 或兼容模型 Key，即可使用同一套 Agent、工具调用、图表和报告能力。

- 本地开发默认仍是 Desktop 模式；公共部署必须设置 `SPECTRA_MODE=public`。
- 在线版**不扫描访问者电脑**，只读取用户主动上传的 CSV、TXT、TSV、DPT、XLSX 文件。
- 上传文件和生成的交付物仅保留在运行内存，最长两小时；服务重启后自动清空。
- 在线版的模型 Key 只在访问者当前浏览器标签页暂存，不会保存到服务器、项目文件或服务日志。
- 仓库已带有 `Dockerfile`，可部署到任意 Docker 托管平台。完整步骤见 [DEPLOYMENT.md](DEPLOYMENT.md)。

面试展示建议：把在线链接放在简历或作品集，面试官可自行上传公开 Demo 数据并体验 Agent；不要让对方上传涉密实验数据，也不要将自己的模型 Key 配置到公开服务端。

## macOS 如何打开

1. 安装 Node.js 20 或更高版本：<https://nodejs.org/>。
2. 双击 `启动光谱Agent.app`（推荐）。它会自动打开终端并启动服务。
3. 终端显示 `Spectra Copilot 已启动` 后，浏览器打开 <http://127.0.0.1:8787>。

`启动光谱Agent.command` 仍保留为备用启动方式。

### 如果 macOS 提示“无法验证”或“未打开”

这是 macOS 对未签名本地脚本的提示。确认这是你信任的项目副本后：

1. 点击“完成”，不要点“移到废纸篓”。
2. 按住 `Control` 点击 `启动光谱Agent.app`，选择“打开”。
3. 在下一次确认框中再次选择“打开”。

仍无法打开时，用终端启动（最稳定）：

1. 在 Finder 中打开本项目文件夹 `光谱计算Agent`。
2. 在文件夹的空白处右键，选择“服务”→“新建位于文件夹位置的终端窗口”。
3. 在新开的终端中输入 `bash`，再按一次空格。
4. 将 `启动光谱Agent.command` 直接拖进终端窗口。终端会自动填入完整文件路径；不要手动改路径。
5. 按回车键运行（不是点“确定”）。首次启动会自动安装依赖，需保持网络连接。
6. 终端显示 `Spectra Copilot 已启动` 后，在浏览器打开 <http://127.0.0.1:8787>。

终端中的命令看起来会类似下面这样：

```bash
bash "/完整路径/光谱计算Agent/启动光谱Agent.command"
```

如果 Finder 右键菜单中没有“新建位于文件夹位置的终端窗口”：先打开“终端”应用，输入 `cd` 后按空格，再把整个 `光谱计算Agent` 文件夹拖进终端并按回车；随后从第 3 步开始操作。

页面已能打开 <http://127.0.0.1:8787> 时，说明服务正在运行，无需再次启动。停止服务请回到终端按 `Control + C`。`启动光谱Agent.app` 未经 Apple 签名；从浏览器下载 ZIP 后，首次打开仍可能需要按住 `Control` 点击并选择“打开”。

## 本地与在线版的隐私边界

- 本地桌面模式只监听 `127.0.0.1`，**不要**将本地模式直接暴露到局域网或公网。
- 本地模式下，网页上传的光谱文件仅保存在本机运行内存中；Desktop 搜索只在当前用户 `Desktop` 目录内查找支持文件。生成的图表和报告保存在本机 `.spectra-artifacts` 目录，可按需自行删除。
- 公共上传演示模式不扫描访问者电脑；上传文件和生成交付物只在服务运行内存中保存，最长两小时，服务重启后自动清空。
- 使用 AI 功能前，请确认你接受所选模型服务的隐私政策与计费方式；共用电脑时请在“AI 设置”中清除 Key。
- 这不是医疗、生产安全或法律决策工具；科研结论应由研究者复核原始数据、实验条件和计算假设。
