# Spectra Copilot

一个面向材料、光学与热管理研究的光谱数据分析 Agent 原型。

它的目标不是固定的“光谱计算器”，而是：**你给一批桌面数据和一句研究任务，它规划、追问、调用本地计算工具，并交付适合任务的图、表、摘要或报告。**

> A local, tool-using spectral-analysis Agent for materials, optics, and thermal-management research.

## 现在能做什么

- 在本地 Desktop 范围内查找，或由用户上传 CSV、TXT、TSV、DPT、XLSX 光谱文件
- 自动判断常见的分隔符、跳过表头和无效行
- 检查重复波长、排序、无效数值、Y 值范围和波段覆盖
- 给出波长单位的“候选判断”，要求用户确认，避免静默换算
- 一次将最多 30 个文件加入同一个任务，逐份保存确认信息
- 只有一个对话入口：文件确认、任务追问、计划、工具轨迹和交付物都在聊天中完成
- 根据任务中的“比较、排序、筛选、汇报、表格、结论”等要求，生成可调整的分析计划与建议交付物
- 使用 DeepSeek 或其他 OpenAI 兼容模型服务进行 Agent 编排；模型先请求受控工具，再依据工具结果回答
- 生成本地 SVG 谱图和 HTML 分析报告；报告可在浏览器中打印成 PDF

## Agent 的职责边界

```text
你的自然语言任务
        ↓
模型层：理解目标、规划步骤、指出需要追问的条件、组织表达
        ↓                       ↑ 接收摘要、确认信息、按需原始行样本和计算结果
本机工具层：读取桌面文件、单位换算、插值、物理积分、导出成果
```

当前仓库已完成本机工具层和首个工具调用循环。模型不能自行浏览文件系统、执行系统命令或伪造计算结果；光谱数值、单位换算和积分结果都由本机工具生成。

这一版本地原型支持用户自带 DeepSeek 或其他 OpenAI 兼容服务的 Key。Key 与模型设置保存在**当前浏览器、当前设备**的本地存储中，直到用户点击“清除 Key”；它们不会写入项目文件、压缩包或服务端日志。每次模型调用由该用户自己的 Key 发起，因此费用由该 Key 所属账户承担。

模型通常只收到文件名、文件 reference、点数、确认后的单位、波段范围与数据提醒等摘要。用户请求排错或查看原始行时，本机工具最多会返回 30 行已授权的原始 X/Y 数据和近似行号给模型；不会把整份桌面文件交给模型。用户主动粘贴或上传图片时，该图片会在本轮发送给所配置的模型服务。若未来把项目部署到公网，必须使用 HTTPS、登录/限流和不记录请求体的服务端日志策略；不能让浏览器直接把 Key 暴露给第三方接口。

## 快速开始

需要 Node.js 20 或更高版本。进入项目目录后运行：

```bash
npm install
npm test
npm start
```

然后在浏览器打开 <http://127.0.0.1:8787>。

## macOS 如何打开

1. 安装 Node.js 20 或更高版本：<https://nodejs.org/>。
2. 双击 `启动光谱Agent.app`（推荐）。它会自动打开终端并启动服务。
3. 终端显示 `Spectra Copilot 已启动` 后，浏览器打开 <http://127.0.0.1:8787>。

`启动光谱Agent.command` 仍保留为备用启动方式。

### 如果 macOS 提示“无法验证”或“未打开”

这是 macOS 对未签名本地脚本的提示。确认这是你信任的项目副本后：

1. 点击“完成”，不要点“移到废纸篓”。
2. 按住 `Control` 点击 `启动光谱Agent.app`，选择“打开”。
3. 在下一次确认框中再次选择“打开”。

仍无法打开时，用终端启动（最稳定）：

1. 在 Finder 中打开本项目文件夹 `光谱计算Agent`。
2. 在文件夹的空白处右键，选择“服务”→“新建位于文件夹位置的终端窗口”。
3. 在新开的终端中输入 `bash`，再按一次空格。
4. 将 `启动光谱Agent.command` 直接拖进终端窗口。终端会自动填入完整文件路径；不要手动改路径。
5. 按回车键运行（不是点“确定”）。首次启动会自动安装依赖，需保持网络连接。
6. 终端显示 `Spectra Copilot 已启动` 后，在浏览器打开 <http://127.0.0.1:8787>。

终端中的命令看起来会类似下面这样：

```bash
bash "/完整路径/光谱计算Agent/启动光谱Agent.command"
```

如果 Finder 右键菜单中没有“新建位于文件夹位置的终端窗口”：先打开“终端”应用，输入 `cd` 后按空格，再把整个 `光谱计算Agent` 文件夹拖进终端并按回车；随后从第 3 步开始操作。

页面已能打开 <http://127.0.0.1:8787> 时，说明服务正在运行，无需再次启动。停止服务请回到终端按 `Control + C`。`启动光谱Agent.app` 未经 Apple 签名；从浏览器下载 ZIP 后，首次打开仍可能需要按住 `Control` 点击并选择“打开”。

## Windows 如何打开

2. 双击 `启动光谱Agent-Windows.bat`。

## 本地使用与隐私

- 服务只监听 `127.0.0.1`，设计为单机本地原型，**不要**将其暴露到局域网或公网。
- 网页上传的光谱文件仅保存在本机运行内存中；当前原型的桌面搜索功能会在当前用户 `Desktop` 目录内查找支持的光谱文件。生成的图表和报告会保存在本机 `.spectra-artifacts` 目录，可按需自行删除。
- 使用 AI 功能前，请确认你接受所选模型服务的隐私政策与计费方式；共用电脑时请在“AI 设置”中清除 Key。
- 这不是医疗、生产安全或法律决策工具；科研结论应由研究者复核原始数据、实验条件和计算假设。
